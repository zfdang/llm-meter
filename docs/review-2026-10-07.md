# Review of main at 3766ea3

Reviewed the native app and state propagation, refresh scheduling, all four provider
adapters and parsers, credential boundaries, persistence, subprocess lifecycle,
packaging, CI, and existing regression coverage. This is source review plus local
fixture/native rendering verification; it does not establish live subscription
compatibility for every installed provider version.

## Findings and changes

### P1: PR packaging received repository write permissions

`package.yml` gave the build job `contents: write` while executing checked-out PR
scripts. Gating the final publishing step did not reduce permissions available to
those earlier scripts. Checkout also retained credentials by default.

The build job now has `contents: read` and `persist-credentials: false`. A separate
release job receives `contents: write` only on pushes to main, downloads that run's
packaged artifacts, and does not check out or run repository scripts. Main builds
continue to create releases. This follows GitHub's documented
[job-level least-privilege guidance](https://docs.github.com/en/actions/tutorials/authenticate-with-github_token).
Actual publishing remains a post-merge integration check.

### P2: gray percentages did not explain all stale states

Gray is intentional for unconfirmed cached readings, retained partial readings,
errors, unknown values, and aged readings. A changed snapshot timestamp alone does
not confirm every metric in a partial response. The prior interface explained
errors but omitted confirmation/age status in the provider row.

The panel now shows cache confirmation, retained-reading, and stale-reading status,
including error status for the monthly provider. Color selection uses a typed tone
computed directly from the metric's freshness and consumed percentage, rather than
parsing a display string's trailing dot. Remaining mode preserves consumption-based
thresholds: green below 50%, orange below 80%, red at or above 80%.

A new native-app regression drives the non-manual refresh path through success
(42%, green), failure (retained 42%, gray), and automatic recovery (85%, red). It checks
published state, labels, and rendered NSHostingView pixels without reconstructing
the view. It passes locally. The reported live symptom is **not reproduced** by this
fixture: there is insufficient evidence to attribute it to SwiftUI color caching.
The new status labels make the reason for a gray reading visible for further live
diagnosis.

### P2: timer depended on the default run-loop mode

The five-second scheduling timer previously used the default run-loop mode. AppKit
tracking/modal interaction can defer that timer. Registering it in common modes
keeps automatic polling and freshness updates eligible during such interaction;
provider intervals and cooldowns still apply. This is a scheduling hardening change,
not proof of the reported gray-color cause.

## Remaining nonblocking items

- `NetworkTransport` rejects responses above 2 MB only after URLSession has buffered
  the body. Timeouts bound duration, but this is not a streaming memory limit. A
  future transport hardening change should abort as bytes exceed the limit.
- CLI subprocesses inherit the environment for compatibility. An explicit allowlist
  remains a separate hardening task and needs real subscription CLI validation.
- Process-group cancellation cannot contain descendants that deliberately leave the
  group; reaping is bounded for an unkillable child. Existing documentation describes
  these limits. The earlier spawn-group race and synchronous cancellation delay are
  already addressed on main.
- Copilot uses an undocumented endpoint. Claude Code subscription CLI reads still
  need live account validation; fixtures verify parsing and command constraints.
- Public distribution still requires Developer ID signing and notarization.

## Localization

The first system language selects Simplified Chinese or English. Explicit Chinese
script takes precedence over region; Traditional Chinese and every other language
fall back to English. UI strings, native menu/window titles, status/errors, countdowns,
metric labels, and allowance units are translated at display time. Provider-reported
model names, protocol parsing, persisted settings, and cached metrics stay unchanged.
The package advertises `en` and `zh-Hans`. Restart after changing system language.
